aio-debian

Script todo en uno de mantenimiento y configuración para Debian: actualiza con apt, habilita contrib y non-free, instala Flatpak/Flathub y mucho más. Software libre (GPL-3.0+).

Instalación rápida

curl -fsSL https://julioayusoalende-hue.github.io/aio-debian/install.sh | sudo bash

O paso a paso (una sola vez)

sudo apt install -y curl ca-certificates
sudo curl -fsSL https://julioayusoalende-hue.github.io/aio-debian/aio-debian.gpg -o /usr/share/keyrings/aio-debian.gpg
sudo tee /etc/apt/sources.list.d/aio-debian.sources >/dev/null <<'EOF'
Types: deb
URIs: https://julioayusoalende-hue.github.io/aio-debian
Suites: stable
Components: main
Architectures: all
Signed-By: /usr/share/keyrings/aio-debian.gpg
EOF
sudo apt update
sudo apt install -o Dpkg::Options::=--force-confnew aio-debian

Versiones de pruebas (testing)

Para recibir antes las novedades, aún sin estabilizar:

curl -fsSL https://julioayusoalende-hue.github.io/aio-debian/install.sh | sudo AIO_SUITE=testing bash

Para volver al canal estable: edita /etc/apt/sources.list.d/aio-debian.sources y pon Suites: stable.

Uso y actualización

sudo aio-debian                       # ejecutar
sudo apt update && sudo apt upgrade   # actualizar
